# 🐂 HiberBull - Meme Coin on Sei

**HiberBull (HIBER)** is a meme coin deployed on the [Sei](https://www.sei.io) blockchain.  
Fueled by community vibes and bullish dreams, HiberBull is here to bring the fun back to crypto.

## 🚀 Features
- ERC20-compliant token with tax mechanism
- Built with Solidity & Foundry
- Deployed on Sei Network (EVM compatible)
- Staking system with monthly rewards
- Auto burn & marketing tax on transfers
